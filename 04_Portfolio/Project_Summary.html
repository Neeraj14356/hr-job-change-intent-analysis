Project Overview

This project examines patterns in candidates' stated intent to change jobs using the HR Analytics: Job Change of Data Scientists dataset. After excluding 65 records with missing experience, the analysis of 19,093 candidates identifies associations across demographics such as professional experience, relevant skill alignment, and geographic development levels. The objective was to provide HR teams with data-driven insights to better understand groups with higher stated job-change intent.

Technical Approach & Skills

Power Query (ETL): Performed data cleaning, handled missing values, and filtered records to ensure a high-quality analysis set.
PivotTables: Aggregated large datasets to calculate intent rates across multiple dimensions.
Data Visualization: Developed an interactive dashboard using PivotCharts and Slicers for dynamic exploration.
HR Analytics: Defined and tracked KPIs such as the "Job-Change Intent Rate" to quantify workforce trends.

Key Insights

  • Overall Intent: Out of 19,093 analyzed candidates, 24.90% (4,754) expressed an intent to change jobs.
  • Experience Pattern: An observed decrease in intent rates exists across experience bands, from 34.31% for early-career candidates (0–5 years) to 15.31% for seasoned professionals (21+ years).
  • Relevance Association: Candidates without relevant experience (n=5,345) showed a 33.84% intent rate, while those with relevant experience (n=13,748) showed a 21.42% intent rate.
  • City Development: Stated intent varied by city development index, with the lowest-index group (≤ 0.60, n=721) showing an intent rate of 57.98%.
  • Data Gaps: 31.0% of records (5,915) lacked company size information. Within this "Not Provided" group, the intent rate was 40.6%, indicating a pattern between missing firmographics and stated mobility.

Interactive Dashboard

To make these findings actionable, I built a dynamic dashboard. It allows stakeholders to filter results in real-time using slicers for Experience Band, Education Level, Gender, and Company Type, transforming static figures into an exploratory tool for identifying groups with higher stated job-change intent.

Analyst Reflection

I learned the importance of data hygiene—specifically handling "Not Provided" values and missing records—and how to use interactive elements to let the data inform the user. This project demonstrates my capability to manage the end-to-end data pipeline, from ETL in Power Query to executive-level visualization.

Note on Data Interpretation: In this analysis, Target = 1 represents a candidate's stated intent to change jobs, not confirmed resignation or attrition. All findings describe associations within the dataset and do not establish a causal relationship.
